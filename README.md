# Hotter Days, Heavier Downpours

DSC 106 final project: an explorable explanation of how climate change is projected to change extreme heat and extreme rainfall, built with D3.js.

- `index.html`, `style.css`: the page
- `crossing.js`: section 1, when each place crosses 1.5, 2, or 3°C (data from Project 3)
- `extremes.js`: sections 2–5, extreme heat days, heavy-rain days, regions, and California summers
- `data/warming.json`: output of the Project 3 notebook
- `data/extremes.json`: output of the export cell in `DSC106_FinalProject.ipynb`

To view locally, run `python3 -m http.server` in this folder, then open http://localhost:8000.
